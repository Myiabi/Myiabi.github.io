# FUNÇÃO DA TRILHA SONORA

## Comandos

### Tocar trilha
- `tocarTrilha('nomeDaTrilha');`  
  Pausa a trilha atual e toca a próxima.

### Pausar trilha
- `pausarTrilha();`  
  Pausa a trilha atual.

### Tocar efeitos sonoros
- `tocarEfeito('nomeDoEfeito', volume);`  
  Toca o efeito sonoro. Volume de 0.0 a 1.0.
